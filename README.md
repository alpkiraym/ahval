# Ahvalu'ş-Şahsiyye · الأحوال الشخصية

Giray Akademi programı: İslam aile hukuku (nikâhın şartları, sîgalar, nikâhın hükmü, evlilik engelleri, velayet, vekâlet, kefâet, eşlerin hak ve ödevleri, mehir, nafaka).

Adres: https://alpkiraym.github.io/ahval/

- 11 ünite, ünite sonlarında hızlı tekrar ve mini test
- Arapça şemalar (Türkçe karşılıklarıyla), karşılaştırma tabloları, kavram kartları
- Görüş eşleştirme (görüş → imam / mezhep), açıklamalı testler
- ⚑ Bildir ile hata bildirimi; Giray Akademi alt çubuğu

## Düzenleme

Kaynak dosyalar `kaynak/` klasöründedir (`01.txt … 11.txt`, `sorular.txt`, `kisiler.txt`, `sinav.txt`, `sablon.html`). Değişiklikten sonra:

```
python3 kaynak/derle.py
```

`index.html` elle düzeltilmez.
